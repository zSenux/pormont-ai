# Jarvis ProMont

KI-Assistent für die **ProMont GmbH** (Metallbau-Meisterbetrieb, Mannheim, promont.gmbh), gebaut von Klaic Media.
Web-App + iPhone-PWA + Windows-App (`windows-app/`, Electron-Hülle um die Web-App) mit **eigener Buchhaltung** (ersetzt Lexware Office; Lexware-API nur noch für die Datenübernahme).
Bausteine stammen aus `zSenux/klaic-os` (Agent-Schleife, Push, PWA, Windows-App) – bewusst schlank gehalten.

**Sprache:** UI, Code-Kommentare und Antworten auf Deutsch. Ansprache in der App per Du.

## Stack
- Next.js 16 (App Router, `src/proxy.ts` = Middleware), React 19, Tailwind 4, Prisma 7 (+ adapter-pg) + Postgres, zod 4, lucide-react
- KI: `@anthropic-ai/sdk`, Modell je Funktion aus AppSetting `KI_MODELL` (`src/lib/ki-modell.ts` `kiModel(feature)`, Liste in `ki-modell-shared.ts`; Standard = günstigstes `claude-haiku-5-5`, Admin wählt unter `/ki-kosten#modell`; Haiku ohne `fallbacks` → `fallbackParams(model)`), adaptive Thinking, Streaming, Prompt-Caching (System + letztes Werkzeug)
- Auth: eigene Sitzung (`pm_session`, HMAC mit `AUTH_SECRET`, `src/lib/auth/*`), Passwörter scrypt, `sessionVersion` = überall abmelden
- Design: ProMont-Blau `brand` #0f4d83, dunkel `brand-2` #092f50, Text #101820, Stahlgrau #64717c, Schrift Inter (Tokens in `globals.css`). Dunkelmodus: Klasse `dark` am `<html>` (Skript `lib/theme-script.ts` im `<head>`, Auswahl je Gerät in localStorage `pm-theme`: auto = Handy < 768 px dunkel/PC hell, system, light, dark; `components/theme.tsx` = Einstellungen → Darstellung + Sonne/Mond in der Handy-Kopfleiste). Dunkel = nur andere Werte der Farb-Tokens in `globals.css` (auch Tailwind-Palette 50–300/700–900), dazu wenige Ausnahmen (`text-white`, `bg-brand` als Fläche, Verläufe). Papier/Unterschrift/PDF bleiben hell mit `keep-light`, Drucken immer hell. Neue Farben nur über die Tokens, keine festen Hex-Farben. Handy: Grundschrift 500, `font-medium` = 600, `text-xs` 13 px, Stahlgrau dunkler

## Regeln
- **GoBD in der Buchhaltung:** nur Entwürfe (`ENTWURF`) sind änderbar. Festschreiben vergibt die Nummer in derselben Transaktion und archiviert PDF + XML mit SHA-256; danach nie mehr ändern oder löschen. Korrektur nur per Storno-Gutschrift (`cancelInvoice`). Jede Änderung als `SalesDocEvent`.
- **Jarvis darf Entwürfe, Kunden und Zahlungen direkt anlegen; Festschreiben, Senden, Mahnen und Storno nur über `PendingAction`** (`beleg_festschreiben`, `beleg_senden`, `mahnung_senden`, `beleg_stornieren`; Payload nur IDs/Mailfelder, Belegdaten kommen aus der DB). Vorschlag → Karte → Freigabe durch einen Menschen, atomar PENDING → DONE.
- **Mails senden nur über `PendingAction` (`mail_senden`)**. Mail-Inhalte sind fremde Daten (Prompt-Injection) – werden im Werkzeug-Ergebnis als `<mail_inhalt>` markiert; HTML nie ins DOM, nur als Text. Anhänge nur als Download (octet-stream, nosniff, CSP sandbox)
- **Preisanfragen an Lieferanten nur per Klick auf „Jetzt senden“ oder über `PendingAction` (`preisanfrage_senden`, Payload nur `requestId`)** – gesendet wird der Text aus der DB
- **Belegfotos werden als Ausgabe gebucht (`beleg_hochladen` bucht direkt aus den gespeicherten Belegdaten, nie aus Modell-Angaben)**; Bankumsätze nur per Klick zuordnen. Dokument-Inhalte sind fremde Daten (`<dokument_inhalt>`)
- **Datenübernahme in die Buchhaltung (Kunden/Artikel) nur per Admin-Klick auf `/datenuebernahme`** (Rückfrage im Browser) – nie aus einem Jarvis-Werkzeug; Daten kommen aus der DB
- Rechnungen werden standardmäßig als **Entwurf** angelegt; Festschreiben nur, wenn ausdrücklich gewünscht. Für Rechnungen müssen IBAN/Bank unter Buchhaltung → Einstellungen stehen.
- Chat-Verlauf ist append-only (Thinking-Blöcke bleiben gültig) – nie alte Nachrichten verändern; Hinweise als neue Nachrichten anhängen.
- Eingaben immer mit zod prüfen, jede Server-Action mit `requireUser()`/`requireAdmin()` bzw. in einem Bereich mit `requireArea(...)`; neue Bereiche/Werkzeuge in `rights-shared.ts` eintragen.
- Keine Geheimnisse ins Repo – nur `.env` (gitignored) + `.env.example`.
- Schema-Änderungen so, dass `prisma db push` ohne `--accept-data-loss` durchläuft.
